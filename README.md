## `~/projects`

### 🛰️ OSINT, Privacy & Security

| Project | What it does | Stack |
|---|---|---|
| **[TelScope](https://github.com/soms3r/TelScope)** | Local-first OSINT dashboard for phone numbers & emails. Twelve modules — carrier/line metadata, mail-domain security (SPF/DMARC/DKIM), RDAP registration lookup, breach & paste exposure. Authorized investigations only. | `Python` `MIT` |
| **[silouder](https://github.com/soms3r/silouder)** | Offline-first Android communicator. E2EE messaging and P2P voice over Bluetooth LE, local WiFi sockets, LoRa mesh (Meshtastic) and Tor — no cell towers, no internet. | `Kotlin` |
| **[backup-fortress](https://github.com/soms3r/backup-fortress)** | Zero-cost, local-first backup utility that encrypts and syncs local data and databases to free cloud tiers. | `JavaScript` |
| **[FB-BG-Checker](https://github.com/soms3r/FB-BG-Checker)** | Background checker for Facebook assets — Business Manager, WABA, ad accounts and users. | `HTML` |
