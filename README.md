## TBA-OpenIntel

I founded **[TBA-OpenIntel](https://github.com/TBA-OpenIntel)** — a suite of 10 open source tools for history, politics, and fact-checking research in **Bengali + English**.

| # | Project | What it does |
|---|---------|-------------|
| 01 | [chronomap-bd](https://github.com/TBA-OpenIntel/chronomap-bd) | Interactive historical timeline map of Bangladesh & South Asia |
| 02 | [sourcevault](https://github.com/TBA-OpenIntel/sourcevault) | Searchable archive of primary sources |
| 03 | [facttrail](https://github.com/TBA-OpenIntel/facttrail) | Fact verification for Bengali + English content |
| 04 | [quoteguard](https://github.com/TBA-OpenIntel/quoteguard) | Political quote verification |
| 05 | [historydot](https://github.com/TBA-OpenIntel/historydot) | Current events → historical pattern finder |
| 06 | [newsconnector](https://github.com/TBA-OpenIntel/newsconnector) | Trending news → historical context engine |
| 07 | [scriptassist](https://github.com/TBA-OpenIntel/scriptassist) | AI script assistant for history-politics YouTubers |
| 08 | [politiciantracker](https://github.com/TBA-OpenIntel/politiciantracker) | Open database of political figures & statements |
| 09 | [mediabias-bd](https://github.com/TBA-OpenIntel/mediabias-bd) | Media bias scorecard for BD & South Asia |
| 10 | [researchkit](https://github.com/TBA-OpenIntel/researchkit) | Master toolkit — all projects in one dashboard |
